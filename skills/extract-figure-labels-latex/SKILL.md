# 图中文字与 LaTeX 提取

## 输入与范围

获取当前选中的图片或明确页码/图号；记录全文或局部、原文或翻译、是否去重、是否要文件。默认按原文逐字提取，保留不同位置的重复出现；可用位置和次数表示重复，不能无说明去重。

先检查图片可读性、分辨率、是否确有用户所说公式。无文字图应报告没有可读文字，不从旧图重建。聊天中提取不修改图，不自动创建额外文件。

## 共同证据规则

- 以当前图像作为转录来源，区分看见、推测和无法辨认。
- 不从历史提示词、领域常识或论文记忆补写；不将纠错后的表述冒充原图。
- 不虚构提取完整率、OCR准确率或核查结果；要求先讨论时只给方案。
- 先放大局部或检查更清晰的当前来源；仍不可读时标记[辨认不清]及位置，不猜补变量。

## 执行步骤

### 1. 建立模块地图

打开实际图像，按真实面板、标题和阅读顺序分区，不为了整齐重组科学关系。无标题时用左上/中央等位置名，说明其为整理标签而非原图文字。

单列连接标注区，覆盖跨模块箭头、外围反馈、主标题、脚注、图例、轴标签、编号与图标内部字符。

### 2. 逐区转录

OCR仅辅助，必须视觉复核。按模块记录原文、位置、重复次数与可读状态。保留大小写、否定词、百分号、单位和上下标；可合并不影响含义的换行。

重点检查：
- offline/online等阶段限定和no/not等否定词；
- 箭头文字、页底小字、曲线旁单变量、圆内编号；
- L/1/l、O/0、v/ν、τ/t、帽号、波浪号和均值横线；
- 全局标题和局部重复标签，不能只提取大标题而遗漏小字。

### 3. 转换数学标记

每个公式与变量给独立可复制源码，使用行内代码或latex代码块；可附渲染效果，不能只有渲染结果。

| 原图含义 | 源码示例 |
|---|---|
| 下标 | \tau_L；t_m；f_{\min} |
| 希腊与算子 | \Delta f；\alpha(x)；\min(a,b) |
| 修饰符 | \hat H；\tilde z；\bar X |
| 变量与普通说明 | c = C(\mathrm{obs}) |
| 省略与箭头 | \ldots；\vdots；\rightarrow |

忠实保留字形，不将普通C改为\mathcal{C}，不根据定义猜补公式。分清功率、能量、时间与单位。代码图标</>按字面字符列出，不改成数学式。波形、连线和勾号不是正文公式；用户要求全部符号时另列图形符号。

### 4. 复核完整性

按原图顺序再次扫描；用清单反向定位每个文字区域。核对否定词、数字、变量和重复位置；长公式逐项检查分子分母、正负号、括号与取值范围。

## 输出格式

默认用中文整理，原文保持原语言：
1. 按模块列标题/说明、公式与变量、连接标注；不存在的类目省略。
2. 普通文字用列表，混有变量的标签用“原文标签｜LaTeX源码”表格。
3. 源码必须放行内代码或代码块，不仅放在普通正文或渲染公式中。
4. 同变量多次出现时注明模块或次数；不同公式不合并。
5. 有疑点时最后列待辨认位置。需要翻译时加独立译文列，不覆盖原文。

## 核查标准与注意事项

- 覆盖全部可读文字，包括边缘、连线旁和图标内部；未读区域明确说明。
- 源码忠于原图、可复制，转录与解释分开。
- 不顺带修图或改写术语。明显错误先忠实转录，再单列提醒。
