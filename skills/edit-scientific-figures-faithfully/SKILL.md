# 科研图件定向编辑

## 输入与工作边界

获取唯一编辑源、删除/替换/保留清单，以及尺寸、透明背景、输出格式。用户选中的附件或指定版本优先，不能替换成历史上较新或更漂亮的图。

先打开实际图片；文件名不等于已经视觉检查。路径不可读时检查当前附件和可用来源，不凭记忆重画。只要求讨论或提示词时不修改文件。

## 共同证据规则

- 先检查指定目标是否存在，区分原图内容、论文事实与编辑判断。
- 授权只覆盖指定变化。发现科学疑点时先指出，不把纠错混入其他保持不变的编辑。
- 不虚构已检查、已修改、像素一致、相似度或数据完整等结果。生成式编辑不自动等于精确保真。
- 非破坏性保存新版本，不擅自覆盖源图、稿件或代码。

## 执行步骤

### 1. 建立变更合同

| 类别 | 记录内容 |
|---|---|
| 修改 | 文字/符号、填色/边框、区域或标签替换 |
| 保留 | 曲线与数据、坐标、箭头、图标、位置、配色、比例 |
| 待辨别 | 兼具装饰或科学含义的元素 |

“全部文字”覆盖标题、说明、数字、变量、公式、图例和脚注。是否包含代码图标、加号、省略号要依据用户是否要求符号及其功能判断。默认删除语言/数学标注，保留结构和物理图形符号；有关键歧义时说明取法或作最小澄清。

去字保留坐标轴和曲线，只去轴标签；去背景框删除填色及包围边框。保留天平砝码、电池外壳、文档纸张、数据区间等前景对象。仅去编号文字时保留圆形标记；仅去字时不顺带去框。去字去框同时要求时不保留空标签卡片。

不得在清除区域新增文件图标、波形、文字或装饰。

### 2. 选择编辑方式

- 可编辑SVG/PPT源优先改真实对象。
- 位图使用当前可用图像编辑工具；适用imagegen时提供准确源图、不变量和修改范围，遵守其参考图与透明背景规则。
- 科学数据和曲线优先从原生源处理。工具不能保证局部精度时说明限制，不伪造逐像素保真声明。
- 不把整图重设计当作定向编辑，不把整张位图放进PPT称为对象级重建。

### 3. 编写约束明确的指令

说明源图角色、唯一允许的变化、保留对象、空白填补方式和画布比例。直接命名易误删的外围反馈箭头、跨区连接、曲线端点与图标内部符号。

按当前图需要用区域编号或坐标辅助定位；坐标仅对本次源图有效。迭代时保留最初源图为对照，明确中间结果只是其派生版本。

### 4. 逐区比较输出

1. 扫描边角、箭头旁、图标内、坐标与页脚，查残字和残符号。
2. 检查大小背景框、填色、轮廓和阴影是否完全按约定处理。
3. 沿连接从起点跟到终点，检查顶部和外围闭环是否被误删、截断或改向。
4. 对比曲线、阶跃/脉冲、节点、图标数量、位置和比例。
5. 检查空白区有没有新图标、空卡片或补画。

发现差异时只修明确区域，再查看完整图。精确保真需求或具体差异风险才需要增加定量图像比较；未比较不报告数值。

## 输出格式

交付实际编辑图，简短说明指定变化和实际保真限制。只有确实核查过才声明保持一致。只讨论模式给变更合同及方案，到此停止。

## 核查标准与注意事项

- 目标版本正确，指定文字/背景清除完整，保留对象完整，没有意外新增对象。
- 输出能打开、比例正确，无涂抹、残字或伪影，细线与反馈箭头保留。
- 新设计转交design-paper-method-figures；转录转交extract-figure-labels-latex。
- 图片转可编辑PPT使用已有nature-image2ppt或scientific-figure-shapes，先检查其实际运行条件，不以本技能替代其对象重建流程。
