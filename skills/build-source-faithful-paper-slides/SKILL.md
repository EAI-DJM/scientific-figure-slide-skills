# 论文原始素材驱动的 PPT

## 输入与工作模式

获取当前论文及必要附录、模板PPT、待诊断PPT、页数/时长/受众和复用要求。诊断只读；先讨论不写文件；只要求提示词则交付提示词；要求制作则交付实际PPTX。

记录本次参数：内容页与封面/附录计数、语言、比例、全部图/表/公式的范围、是否允许新绘、可编辑性、顶部段落字数与行数、密度和提示词长度。不得固化历史四页/五页、方图/横图、高密度/留白偏好。

先检查材料可读、模板存在以及页数/覆盖/可读性兼容。模板缺失时不声称继承母版；只有用户允许自定风格才作明示选择。

## 共同证据规则

- 根据实际稿件、相关代码和已提供或已运行的结果判断，不从摘要记忆补实验数据，不把未运行代码说成验证结果。
- 区分原文事实、重新计算、设计说明和推断，不把作者讨论强化为证明。
- 文献、公式、单位、分母、对比对象和结果须可追溯，不凭曲线外观估精确值，不伪造缺失表格。
- 先讨论时不修改源文件。获授权制作新版本时保留论文、代码、图和PPT原件。

## 执行步骤

### 1. 检查论文与成品

阅读目标内容和实验说明，形成问题、机制、证据、贡献与适用边界的主线。按需核查代码/结果；材料口径有差异时记录来源，不暗选更有利结果。

诊断已有PPT时渲染全部页面，逐页给出位置/对象、具体问题、影响、改法与优先级。区分实际观察和设计判断，不以通用清单冒充逐页诊断。

### 2. 建立素材与证据索引

按要求逐页识别图、子图、表、公式，区分PDF页码和印刷页码。只有要求全量提取公式才强制全量；尽量用所有图不等于无条件塞入全部推导。

| 素材ID | 类型/原编号 | PDF页码/位置 | 内容与用途 | 提取方式/原比例 | 拟用页/未用原因 |
|---|---|---|---|---|---|

优先原矢量或无损内嵌图。复合图不能由单一内嵌位图完整恢复时，按完整图框高分辨率裁切；600dpi是按需要选择的参数，不是通用硬标准。去无用页边空白，不截断图例、单位、子图号和科学内容。

保存原始比例，插入时仅等比缩放：
W_new / W_source = H_new / H_source。
不得分别拉伸宽高。裁剪应明确范围，不因填满页面而损失证据。

### 3. 学习模板与安排叙事

逐页检查比例、母版、标题、字体、颜色、边距、页脚与组件。记录新页来源模板页和继承组件；不能只取颜色后声称复用母版。只有模板截图时说明继承能力限制。

沿论文论证安排每页主要任务，不机械套固定四页结构。保持系列语言，按图表结构变化布局。

顶部100—150字、3—4行只在本次要求时执行，并用实际宽度、字体和换行核查。高密度通过合理组合子图、减重复与裁无用白边实现，不能无限缩小字号。

制作前估算覆盖与可读性。固定页数无法同时容纳全部素材和可读文字时，给出具体冲突和可行排法，提出最少必要选择。不得悄悄增页、漏图或全部缩成不可读缩略图；也不以时间经过当作用户同意。

### 4. 图表与公式处理

- 原图优先，保留数据、坐标、曲线、图例及方法映射；允许明确裁剪、局部放大与外置标注。未经授权不重绘数据曲线，不随意更换原图颜色。
- 表格可重制为原生可编辑表，逐单元格核对数值、单位、列名、统计量、显著性和比较对象。有完整原文数据且任务需要时才计算派生量，注明公式与来源。
- 公式仅来自实际论文，检查符号、条件、编号和上下标；按需求保留清晰裁图或核对后的可编辑公式。推导转备注/附录须符合覆盖和页数约定。
- 新示意图只解释已授权逻辑，标为示意/重绘，不冒充论文原图或真实结果。

### 5. 制作并核查

制作前读取当前可用Presentations/PDF技能以确定工具和渲染流程，不写死本机路径或过期依赖。

标题、正文、标注、箭头和重制表尽量用原生对象，原始论文图可保留图片。整页截图放回PPT是图片版，不能称为对象级可编辑。单图重建转交已有nature-image2ppt或scientific-figure-shapes，不另起重复重构流程。

渲染最终全部页面并逐页检查：变形、清晰度、溢出、遮挡、箭头、裁切、字体替换、模板残留和证据一致性。按实际展示尺寸阅读；缩略图只查主次，不能替代全尺寸检查。

核对全部数字与公式；原数据允许时检查派生计算。按需求检查PPT对象/包结构以确认编辑性。修正后重渲染相关页；未打开PowerPoint不声称在该应用中验证。

## 输出格式

- 诊断：逐页问题和改法，区分观察与判断。
- 提示词：可复制完整提示词，包含当前输入、素材策略、版式参数、交付和核查要求，满足本次字数，不声称已生成PPT。
- 制作：实际PPTX与预览；按要求提供逐页设计、图表公式与页码映射、关键数字核对表、模板对应关系。只交付真正生成的文件。

## 验收标准与注意事项

1. 页数与覆盖符合当前约定，指定但未用的素材有处理说明。
2. 原图/公式没有非等比变形，重制表可追溯且未改变数据意义。
3. 标题与证据一致，没有无依据的最优/提升声明。
4. 模板继承可说明，主要对象可读，无溢出与意外裁切。
5. 原生对象和图片边界说明准确，文件可打开，验证声明符合实际操作。
