# 科研图件与论文汇报 Skills

面向科研工作中的方法图设计、图件定向编辑、图中文字与公式转录，以及优先复用论文原图的学术汇报。

本仓库提供四个独立工作流 Skill。每个 Skill 明确输入、执行步骤、交付格式和核查标准；根据当前材料判断，不将某篇论文、某次实验或某一种版式固化为通用规则。

## Skill 一览

| Skill | 解决的问题 | 常见请求 |
|---|---|---|
| [design-paper-method-figures](skills/design-paper-method-figures/SKILL.md) | 从稿件或研究想法组织科学关系，设计思路图、方法图和技术路线，支持讨论、提示词与成图 | 根据第三章设计方法总览图；先写绘图提示词 |
| [edit-scientific-figures-faithfully](skills/edit-scientific-figures-faithfully/SKILL.md) | 针对选中原图去字、去框、换标签或局部修正，并检查保留对象 | 去除全部文字和背景框，其他保持不变 |
| [extract-figure-labels-latex](skills/extract-figure-labels-latex/SKILL.md) | 按原图模块逐字转录，保留重复位置，为变量和公式提供 LaTeX 源码 | 提取全部文字，变量给我可复制的 LaTeX |
| [build-source-faithful-paper-slides](skills/build-source-faithful-paper-slides/SKILL.md) | 提取和复用论文原图与公式，重制可编辑表格，按模板组织汇报与逐页诊断 | 用论文原图做五页汇报；先逐页指出视觉问题 |

## 使用方式

在支持 SKILL.md 的智能体环境中，按该环境的安装方式导入需要的独立 Skill 目录。各环境的安装入口、技能发现机制和调用语法可能不同；将文件上传到 GitHub 本身不会自动安装到智能体中。

可以通过环境支持的 Skill 调用入口，或在请求中给出相应技能名称和材料。以下示例用于说明任务边界，不代表所有环境都采用同一种调用语法。

### 方法图设计

> 使用 design-paper-method-figures。请阅读附件第三章，先讨论方法图应包含哪些模块以及模块间的连接关系，暂不修改文件。目标是双栏论文中的英文方法总览图。

需要提供：当前论文或研究想法、目标章节、使用位置、交付模式，以及比例、语言和格式等要求。没有稿件的概念任务可依据用户说明开展，但不能宣称方法已经实现或验证。

### 图件定向编辑

> 使用 edit-scientific-figures-faithfully。以我选中的图片为唯一编辑源，删除文字、变量和背景框，保留曲线、反馈箭头、物理图标及其位置，输出一个新版本。

需要提供：准确源图、修改范围和保留清单。文字标签、背景容器、物理对象分别判断。生成式编辑不自动等于像素保真，需要查看实际输出并对照检查。

### 文字与 LaTeX 提取

> 使用 extract-figure-labels-latex。按原图模块提取全部文字，不去重；公式和变量同时给出可复制的 LaTeX 源码。看不清的地方标记出来，不要猜补。

需要提供：清晰图片或明确页码、提取范围，以及是否需要翻译。输出保持原文，转录和解释分别组织。

### 论文原始素材驱动的 PPT

> 使用 build-source-faithful-paper-slides。根据论文及模板制作五页中文内容页，优先复用原图和公式，表格重制为可编辑对象。先检查页数、覆盖范围和可读性是否兼容，再给出逐页方案。

需要提供：论文及相关附录、实际模板、内容页数及封面计数方式、受众、时长，以及素材覆盖和可编辑性要求。只要求提示词时输出提示词；明确要求制作时才输出实际 PPTX。

## 共同原则

1. 先检查请求前提，依据实际稿件、代码和结果判断。
2. 区分原文事实、实现状态、实验观察、设计推断和待确认内容。
3. 不虚构文献、实验、性能数据、图片内容或文件修改结果。
4. 明确要求先讨论时保持只读，不擅自改论文、代码、图片或幻灯片。
5. 保留源文件，用新版本交付获授权的修改。
6. 页数、比例、密度、语言、字号和素材覆盖以当前任务为准。
7. 检查真实成品，不能用提示词正确替代成图正确，也不能把整页截图称为对象级可编辑 PPT。

## 工具与能力边界

本仓库是工作流指令集合，不包含大模型服务、图像生成模型、OCR 引擎或 PowerPoint 制作运行时。实际能力取决于使用环境提供的文件读取、图片查看、图像编辑、PDF、演示文稿与渲染工具。

- 方法图：精确数据图应使用实际数据与可复现绘图工具；概念插图可使用环境提供的图像生成工具。
- 图件编辑：优先修改原生可编辑源；位图需要适当的图像编辑能力。
- 文字提取：OCR 可辅助，但仍需视觉复核；无法辨认的内容应明确标记。
- PPT 制作：需要支持实际 PPTX 输出和渲染检查的工具。
- 图片转对象级可编辑 PPT：由现有的 nature-image2ppt、scientific-figure-shapes 或同等能力工作流承担。本仓库未打包这些外部 Skill，也不保证安装本仓库后自动具备这些能力。缺少对应工具时应说明限制，不能用整图嵌入代替对象级重建。
